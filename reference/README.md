# Reference mods

Real-world mod examples. The agent reads them to learn Victoria 3 (pdx-script) modding patterns.
Do not edit these files. Copy the pattern you need into `your_mods/<ModName>/`.

- `example_mod/` — the **minimal runnable sample**, which must pass `validate_mod`. It holds one
  additive scripted modifier and a bilingual localization. Start here for the bare skeleton.

v1 ships no other pattern mods: the real-world Workshop mods are deliberately not copied in (see the
port plan, decision 6). Add richer samples later, with an agreed license source.
