# Character modding

[Characters](https://vic3.paradoxwikis.com/Character) are defined either with character templates in /common/character\_templates/ or the `create_character` [effect](./Effect.md). Starting characters are found in /common/history/characters/, and many characters are defined in events or other effects as well.

Character templates can be used with the `create_character` effect to generate characters, or they can appear semi-randomly if a usage block is defined.

## Character templates
Character templates are defined in /common/character\_templates/, as an example:

```
usa_rockefeller_character_template = {
    first_name = John
    last_name = Rockefeller
    historical = yes
    dna = dna_john_d_rockefeller
    culture = cu:yankee
    female = no
    religion = rel:protestant
    ideology = ideology_moderate
    interest_group = ig_industrialists
    birth_date = 1839.6.8
    traits = {
        ambitious
        persistent
        basic_entrepreneur
    }
    executive_usage = {
      country_trigger = {
        exists = c:USA
        this = c:USA
      }
      company_trigger = {
        is_company_type = company_type:company_standard_oil
      }
      earliest_usage_date = 1875.1.1
      latest_usage_date = 1915.1.1
      chance = 100
    }
    commander_usage = {
      country_trigger = {
        exists = c:USA
        this = c:USA
      }
      role = general
      earliest_usage_date = 1836.1.1
      latest_usage_date = 1860.1.1
      chance = 75
    }
}
```

Character template parameters

| Parameter | Function | Example | Required |
| template\_key | Unique template identifier | usa\_rockefeller\_character\_template |  |
| first\_name | - Character's first name, points to a localization key - Set to `culture` for a random name from character's culture | first\_name = John |  |
| last\_name | - Character's last name, points to a localization key - Set to `culture` for a random name from character's culture | last\_name = Rockefeller |  |
| historical | Indicates the character is historical | historical = yes |  |
| dna | Refers to a defined character appearance | dna = dna\_string |  |
| female | Sets character as female, defaults to male | female = yes |  |
| culture | - Sets character's culture - Use `primary_culture` or `ig_before_primary_culture` if not using a specific culture | culture = cu:yankee |  |
| religion | - Sets character's religion - Defaults to religion of character's culture | religion = rel:protestant |  |
| age | Sets character's age at generation | age = 36 |  |
| birth\_date | - Sets character's birth date, calculating age at generation - Overrides `age` | birth\_date = 1812.1.1 |  |
| interest\_group | Sets interest group affiliation | interest\_group = ig\_devout |  |
| ideology | Sets character's ideology | ideology = ideology\_moderate |  |
| traits | Sets predefined traits | traits = { cautious } |  |
| trait\_generation | Generates traits on character generation | trait\_generation = { effects } |  |
| commander\_rank | - Sets a commanders rank on generation - Use `default` or a scripted rank | commander\_rank = commander\_rank\_2 |  |
| ruler | Sets character as ruler when generated | ruler = yes |  |
| heir | Sets character as heir when generated | heir = yes |  |
| ig\_leader | Sets character as interest group leader when generated | ig\_leader = yes |  |
| is\_general | Sets character as a general when generated | is\_general = yes |  |
| is\_admiral | Sets character as an admiral when generated | is\_admiral = yes |  |
| is\_agitator | Sets character as an agitator when generated | is\_agitator = yes |  |
| on\_created | Runs effects on the character when generated | on\_created = { effects } |  |

Character templates can include one or more **usage** blocks, which allow the template to be used as a randomly generated character, rather than generating the character by effect. Once a template has been generated by a usage block or `create_character`, it cannot be generated by a usage block again.

Usage parameters (template only)

| Main parameters | | Function | |
| interest\_group\_leader\_usage | | Sets character as a potential randomly generated interest group leader | |
| agitator\_usage | | Sets character as a potential randomly generated agitator | |
| commander\_usage | | Sets character as a potential randomly generated commander | |
| executive\_usage | | Sets character as a potential randomly generated executive | |
| Sub parameters | Sub-parameter of | Function | Required |
| country\_trigger | any main parameter | Trigger in country scope to determine if usage is valid |  |
| interest\_group\_trigger | - interest\_group\_leader\_usage - agitator\_usage | Trigger in interest group scope to determine if usage is valid |  |
| company\_trigger | executive\_usage | Trigger in company scope to determine if usage is valid |  |
| role | commander\_usage | Determines role type, `admiral` or `general` |  |
| earliest\_usage\_date | any main parameter | Sets earliest date usage block is valid |  |
| latest\_usage\_date | any main parameter | Sets earliest date usage block is valid |  |
| chance | any main parameter | Sets chance (from 0-100) of template being used on next valid generation |  |

### Character names
*See also: [Localization](./Localization.md)*

**NOTE:** All text presented to the player ***must*** be done through localization keys. Unlocalized character names default to a random name from the character's culture.

Base game character names are defined in /Victoria 3/game/localization/<language>/names\_l\_<language>.yml; new character names can be defined in any localization file. Character names can be assigned to [cultures](./Culture modding.md), or used only for specific character templates.

### Ruler Selector
Adding characters to the ruler selector can be somewhat finicky.

is\_for\_ruler\_selector = yes

Is required. It seems to also be necessary that your characters be set to an IG leader with an interest\_group\_leader\_usage if you wish for them to appear in the selector.

## Create character effect
The [effect](./Effect.md) `create_character` can use a defined character template, define a character using the same parameters as character templates, or use a template then modify it with additional parameters.

## Character history
Starting characters can be found at /common/history/characters/. They can be created from templates or direct definitions in `create_character`

## Character traits
Character traits are defined in /common/character\_traits/

When adding modded traits instead of modifying existing vanilla traits, create a new file.

```
notorious = {
  type = condition                            # Can be one of personality, skill, or condition. Each category is limited by defines. Random traits can be applied based on a particular type.
  texture = "gfx/interface/icons/character_trait_icons/direct.dds"  # The trait's texture asset
  character_modifier = {                      # Applies to the Character regardless of role
    character_popularity_add = 25
  }

  command_modifier = {                        # Applies to the Character, their Military Formation, and any Combat Units under the Character's command, assuming the unit is fully Mobilized (or does not need to Mobilize)
    unit_kill_rate_mult = 0.1
  }
  
  country_modifier = {                        # Applies to the Character's Country if they are the Ruler of it
    state_turmoil_mult = 0.1
  }
  
  agitator_modifier = {
    political_movement_radicalism_add = 0.15  # Applies to the Character's Political Movement
  }
    
  interest_group_modifier = {                 # Applies to the Character's Interest Group if they are the Leader of it
    interest_group_pol_str_mult = -0.05
    interest_group_pop_attraction_mult = 0.1
  }

  executive_modifier = {                      # Applies to the Character's Company if they are the Executive of it
    building_cash_reserves_mult = -0.1
  }

  possible = {                                # Used to determine if this trait is a valid random choice
    popularity < 0                            # Does NOT impact the validity of the trait once it's acquired
  }

  weight = {                                  # Script value to determine how likely it is the character will randomly get this trait, compared to other traits in its category. Default 1
    value = popularity
    multiply = -1
  }

  replace = {                                 # When the character gains this trait, any traits they have in the following list are removed
    famous
    wicked
  }

  value = 2                                   # How much this trait is "worth" in experience levels traits. Default 1
                                              # Used to determine whether the character is owed more traits, and which trait category is overrepresented
}
```

### Trait localization
*See also: [Localization](./Localization.md)*

Traits generate two localization keys: `<trait_name>` and `<trait_name>_desc`, for the name and flavor description.
