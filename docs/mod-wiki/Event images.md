# Event images

This article has been verified for the current version (1.13) of the game.

*See also: [Event modding](./Event modding.md)*

Event images in Victoria 3 are short videos in [.bk2](https://en.wikipedia.org/wiki/Bink_Video) format.

Event images are used with media aliases defined in game/gfx/media\_alias/ which include both a video and audio component. Medias aliases for DLC event images also have a fallback to another alias in case that DLC is not enabled.

Some events use a static background with one or two characters relevant for the event shown. These events reference a gui window instead of a media alias.
